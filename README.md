# 镍钛管弯曲刚度计算器 | NiTi Tube Bending Stiffness Calculator

一个无需后端、可部署到 GitHub Pages 的静态网页工具。输入镍钛管长度、外径、内径和弹性模量，计算空心圆管截面惯性矩、材料弯曲刚度 EI，以及理想悬臂梁自由端的等效刚度。

## 功能

- 输入管材长度 L、外径 OD、内径 ID。
- 弹性模量 E 支持预设参考值和手动修改。
- 同时计算 EI 与悬臂梁端部等效刚度 k。
- 添加多组规格并比较计算结果。
- 绘制端部刚度 k 与梁长 L 的关系曲线。
- 导出 CSV 报告；使用浏览器打印功能另存为 PDF。
- 纯 HTML、CSS、JavaScript，无需服务器、数据库或第三方依赖。

## 计算公式

空心圆截面惯性矩：

\[
I = \frac{\pi}{64}(OD^4-ID^4)
\]

材料弯曲刚度：

\[
EI = E I
\]

理想悬臂梁自由端受横向集中力时：

\[
k = \frac{3EI}{L^3}
\]

### 单位换算

- 输入长度、外径、内径：mm
- 输入弹性模量：GPa
- 程序内部换算：1 GPa = 1000 N/mm²
- 截面惯性矩：mm⁴
- EI：N·mm²，同时显示 N·m²
- k：N/mm

注意：EI 是截面与材料的弯曲刚度，不包含梁长；对于上述悬臂梁边界条件，端部等效刚度 k 才与长度有关，且 \(k \propto 1/L^3\)。

## 本地运行

1. 下载或克隆仓库。
2. 直接用浏览器打开 `index.html`。
3. 输入参数并点击“计算刚度”。

无需 `npm install` 或构建步骤。

## 发布到 GitHub Pages

1. 在 GitHub 创建仓库，例如 `niti-tube-bending-calculator`。
2. 将 `index.html`、`style.css`、`script.js`、`README.md` 上传到仓库根目录。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. Branch 选择 `main`，目录选择 `/ (root)`，点击 **Save**。
6. 等待部署完成。页面地址通常为：

   `https://你的GitHub用户名.github.io/niti-tube-bending-calculator/`

如果仓库名为 `你的GitHub用户名.github.io`，则网址通常是 `https://你的GitHub用户名.github.io/`。

## 使用说明

- “弹性模量预设”只是便于初步估算的参考输入，不代表所有镍钛材料的真实模量。
- 可以为每组规格分别输入 E；修改“默认弹性模量”会批量更新现有规格的 E。
- 曲线显示的是不同长度下的悬臂梁端部等效刚度；图表纵轴采用对数刻度，以便观察跨数量级变化。
- CSV 按逗号分隔，使用 UTF-8 BOM，便于常见电子表格软件识别中文。

## 重要工程限制

镍钛合金可能表现出超弹性、应力诱发马氏体相变、温度依赖、滞回和加载历史相关性。其有效弯曲响应可能随应变、温度、相态、热处理、材料批次及测试方法变化。

当前版本使用均匀、各向同性、线弹性梁理论和理想悬臂梁边界条件。它没有模拟：

- 超弹性本构、相变平台与滞回；
- 大挠度、局部屈曲、塑性或残余应变；
- 夹具柔度、接触、摩擦和实际支撑边界；
- 管材壁厚偏心、椭圆度、缺陷和尺寸公差；
- 频率、加载速率及温度变化。

因此，计算值适合用于规格初筛和趋势比较，不应直接作为医疗器械设计放行或性能验证依据。正式使用时，应使用材料供应商针对具体状态和温度提供的数据，并通过与实际夹具和测试方法一致的弯曲测试验证。
